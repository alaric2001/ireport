IReport

Platform pelaporan infrastruktur berbasis web — dibangun dengan Laravel 10 dan PHP 8.2

IReport adalah sistem pelaporan infrastruktur publik yang memungkinkan warga melaporkan kerusakan seperti jalan berlubang, lampu mati, dan trotoar rusak. Laporan dapat diupvote oleh sesama warga untuk menentukan prioritas penanganan, dan dikelola oleh Admin yang berwenang mengubah status serta mempublikasikan berita terkait.

Proyek ini dikerjakan sebagai portofolio akademik oleh tim 5 orang. Seluruh fitur berjalan di atas stack Laravel 10 yang diupgrade dari versi 6, dengan migrasi penuh ke PHP 8.2.

Quickstart

Menjalankan Lokal

Pastikan sudah menginstal PHP 8.2, Composer, MySQL, dan Node.js di mesin lokal.

bash — clone & install 
# 1. Clone repository
git clone https://github.com/alaric2001/IREPORT.git
cd IREPORT

# 2. Install PHP dependencies
composer install

# 3. Salin konfigurasi environment
cp .env.example .env
php artisan key:generate
.env — konfigurasi database 
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=db_ireport
DB_USERNAME=root
DB_PASSWORD=
bash — migrasi & seeding 
# Buat database di MySQL terlebih dahulu, lalu:
php artisan migrate --seed

# Atau jika ingin reset:
php artisan migrate:fresh --seed

# Jalankan server development
php artisan serve

Setelah seeding, semua akun pengguna menggunakan password 123 (di-hash dengan bcrypt). Admin default: admin@example.com

Di Windows, jika Composer gagal dengan error file_put_contents, tambahkan folder project ke exclusion Windows Defender sebelum menjalankan composer install.

Keamanan

Lapisan Keamanan Sistem

IReport menerapkan beberapa mekanisme keamanan bawaan Laravel untuk melindungi data pengguna dan mencegah akses tidak sah.

Password Hashing (bcrypt)

Seluruh password pengguna di-hash menggunakan Hash::make() Laravel dengan algoritma bcrypt. Password plaintext tidak pernah disimpan di database.

CSRF Protection

Semua form POST/PUT/DELETE dilindungi token CSRF bawaan Laravel melalui middleware VerifyCsrfToken. Setiap request melewati validasi token.

Role-Based Access Control

Kolom role di tabel users mengontrol akses. Middleware auth memblokir akses halaman admin dan reporter dari pengguna tanpa role yang sesuai.

File Upload Validation

Upload foto laporan dan profil divalidasi tipe MIME dan ukuran file di sisi server sebelum disimpan ke direktori public/.

Input Sanitization

Middleware TrimStrings otomatis memotong whitespace. Semua input tervalidasi melalui Laravel Form Request sebelum diproses controller.

Session Authentication

Autentikasi berbasis session menggunakan Laravel Auth scaffolding (laravel/ui). Session diinvalidasi saat logout, mencegah session fixation.
