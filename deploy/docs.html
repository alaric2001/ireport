IReport adalah sistem web fullstack yang memungkinkan warga melaporkan kerusakan infrastruktur (jalan berlubang, lampu mati, trotoar rusak). Laporan dapat di-upvote, dikomentari, dan dikelola statusnya oleh Admin. Dibangun sebagai proyek portofolio akademik tim 5 mahasiswa menggunakan Laravel 10 yang diupgrade dari basis kode Laravel 6.

Upgrade Path: Proyek ini di-upgrade dari Laravel 6 ke Laravel 10 — mencakup migrasi ke anonymous class migrations, FQCN routes, penggantian fideloper/proxy ke built-in TrustProxies, dan refactor Handler.php ke interface Throwable.

Quickstart

Menjalankan Lokal

Prasyarat: PHP 8.2+, Composer 2.x, MySQL/MariaDB, Git.

bash — setup 
git clone https://github.com/alaric2001/IREPORT.git && cd IREPORT
composer install
cp .env.example .env && php artisan key:generate
.env — database 
DB_CONNECTION=mysql
DB_DATABASE=db_ireport
DB_USERNAME=root
DB_PASSWORD=
bash — migrate & run 
php artisan migrate --seed   # atau migrate:fresh --seed untuk reset
php artisan serve            # http://localhost:8000

Semua akun seed menggunakan password 123 (bcrypt). Di Windows, tambahkan folder project ke exclusion Windows Defender jika composer install gagal dengan error file_put_contents.

Konvensi

Konvensi Kode Laravel 10

Beberapa konvensi penting yang diterapkan dalam proyek ini — terutama terkait upgrade dari Laravel 6.

1. Model di app/ — bukan app/Models/

Proyek ini mewarisi struktur Laravel 6 di mana semua Model berada langsung di folder app/. Namespace tetap App\ModelName.

app/Laporan.php 
namespace App;   // BUKAN App\Models

use Illuminate\Database\Eloquent\Model;

class Laporan extends Model {
    protected $table = 'laporan';
    protected $fillable = ['judul', 'deskripsi', 'foto', 'provinsi', 'vote', 'status', 'user_id'];
}

2. Routes FQCN — Fully Qualified Class Name

Laravel 10 tidak lagi menyuntikkan namespace otomatis ke dalam routes. Semua controller harus di-import secara eksplisit.

routes/web.php 
// ✅ BENAR — Laravel 10 (FQCN)
use App\Http\Controllers\LaporanController;
Route::get('/laporan', [LaporanController::class, 'index']);

// ❌ SALAH — string syntax (hanya bekerja di Laravel 6/7)
Route::get('/laporan', 'LaporanController@index');

3. Anonymous Class Migrations

Laravel 10 menggunakan anonymous class untuk migration agar tidak ada konflik nama class.

database/migrations/xxxx_create_laporan_table.php 
return new class extends Migration {
    public function up(): void {
        Schema::create('laporan', function (Blueprint $table) {
            $table->id();
            $table->string('judul');
            $table->unsignedBigInteger('user_id');
            $table->foreign('user_id')->references('id')->on('users');
            $table->timestamps();
        });
    }
    public function down(): void { Schema::dropIfExists('laporan'); }
};

4. Seeder Namespace

database/seeders/DatabaseSeeder.php 
namespace Database\Seeders;  // folder database/seeders/ (bukan database/seeds/)

class DatabaseSeeder extends Seeder {
    public function run(): void {
        $this->call([
            UserSeeder::class,     // urutan penting — dependency order
            ProfileSeeder::class,
            BeritaSeeder::class,
            LaporanSeeder::class,
            KomentarSeeder::class,
            OurteamSeeder::class,
        ]);
    }
}

Penting: FoundationServiceProvider harus tetap ada di config/app.php providers. Jika dihapus, akan muncul error Target [MaintenanceMode] is not instantiable karena binding kontrak tidak terdaftar.

Keamanan

Lapisan Keamanan

bcrypt Password Hashing

Semua password di-hash dengan Hash::make(). Password plaintext tidak pernah disimpan. Seeder menggunakan Hash::make('123') untuk semua akun awal.

CSRF Protection

Middleware VerifyCsrfToken aktif untuk semua form POST/PUT/DELETE. Setiap request melewati validasi token CSRF bawaan Laravel.

RBAC via CheckRole Middleware

Middleware CheckRole membaca kolom role (int 0/1/2) dari tabel users dan memblokir akses ke route yang memerlukan level lebih tinggi.

File Upload Validation

Upload foto laporan dan profil divalidasi tipe MIME dan ukuran di sisi server sebelum disimpan ke direktori public/.

Input Sanitization

Middleware TrimStrings memotong whitespace otomatis. Semua input tervalidasi melalui Laravel Form Request sebelum diproses controller.

Session Authentication

Auth berbasis session menggunakan Laravel UI. Session diinvalidasi saat logout — mencegah session fixation attack.
