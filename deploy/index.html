Arsitektur

Pola MVC Laravel

Setiap request melewati Router → Middleware → Controller → Model → View sebelum kembali ke browser.

Router & Middleware

routes/web.php dengan FQCN controllers. Middleware Auth, CSRF, dan CheckRole menjaga akses.

Controller & Model

Controller menangani business logic, Model Eloquent ORM memetakan 6 tabel database. Model berada di app/ langsung.

Blade View

Template Blade dengan layout @extends dan @section. Bootstrap 4 untuk UI, JavaScript ES6+ untuk interaksi.

Fitur Sistem

6 Fitur Utama

Setiap fitur terhubung langsung ke tabel database yang sesuai. Badge monospace menunjukkan nama tabel/kolom di schema.

RBAC System

3 Level Hak Akses

Kolom users.role mengontrol akses. Middleware CheckRole memblokir route berdasarkan nilai integer 0 / 1 / 2.
